# Contributing

Contributions should improve the playbook without turning it into an unmaintainable
catalog.

1. Open a framed issue using the learning experiment form.
2. Keep one pull request focused on one observable outcome.
3. Explain non-goals, evidence, risk, and rollback.
4. Do not submit secrets, personal data, confidential material, or copied content
   without a compatible license.
5. Treat AI-generated contributions as drafts: verify behavior, sources, and license
   compatibility before submission.

Small corrections may skip a separate issue when their intent and validation are
obvious in the pull request.
