# Publication Gate

Complete this review before making a repository, release, report, dataset, or demo
public. A failed required item means **hold**, not “publish with good intentions.”

## Content and value

- [ ] Purpose, audience, status, setup, validation, and limitations are clear.
- [ ] The artifact is useful without access to private context.
- [ ] Claims match their current [Evidence Ladder](EVIDENCE-LADDER.md) level.
- [ ] Links, commands, examples, and screenshots were checked.

## Secrets, data, and identity

- [ ] Current files, branches, tags, and complete Git history contain no credentials.
- [ ] Personal, customer, employer, and confidential data is absent or approved.
- [ ] Example values are unmistakably synthetic.
- [ ] Local secret files are ignored and documented.

## Ownership and maintenance

- [ ] Code, text, assets, datasets, and dependencies have compatible licenses.
- [ ] The repository has a deliberate license.
- [ ] Security reporting and maintenance expectations are documented.
- [ ] Stale or experimental status is visible where relevant.

## Software and AI risk

- [ ] Automated workflows use minimal permissions and pinned dependencies where
  appropriate.
- [ ] Important failure and adversarial cases were tested.
- [ ] AI data flow, limitations, human approval points, and fallback are documented.
- [ ] Publication does not grant unintended access to infrastructure or external
  systems.

- **Reviewer:**
- **Date:**
- **Decision:** Publish / Publish sanitized summary / Hold
- **Evidence reviewed:**
- **Unresolved limitations:**
- **Follow-up issue:**

The final decision must be made by a human. Checking boxes is evidence of a review,
not a guarantee that no risk exists.
